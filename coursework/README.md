## Сборка .docx

```bash
pip install pypandoc_binary python-docx
python coursework/build_docx.py coursework/v20 coursework/v25
```

В каждой папке появляются `kursovaya.docx` (оформление по правилам ниже, формулы — объекты Word) и, если установлен
Word, `kursovaya.pdf`; скрипт печатает число страниц. Титульный лист, содержание и рисунок 1 вставить вручную.

## Перенос в Word

- Шрифт Times New Roman 14, межстрочный интервал 1,5, абзацный отступ 1,25 см, выравнивание по ширине;
  поля: левое 30 мм, правое 15 мм, верхнее и нижнее 20 мм; нумерация страниц — внизу по центру, на титуле не ставится.
- Заголовки «ВВЕДЕНИЕ», «ЗАКЛЮЧЕНИЕ», «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ» — прописными, по центру;
  главы — с новой страницы, «1 ТЕОРЕТИЧЕСКИЕ…» с абзацного отступа; точка после номера и заголовка не ставится.
- Формулы записаны в LaTeX (`$$ … $$`); `build_docx.py` переводит их в формулы Word. Вручную: «Вставка → Уравнение»,
  режим LaTeX, вставить текст между `$$` без `\qquad (N)`, «Преобразовать». Номер формулы — справа в круглых скобках.
- Таблицы и рисунки: «Таблица 1 – Название» над таблицей, «Рисунок 1 – Название» под рисунком; в таблицах — 12 пт,
  одинарный интервал.
- Ссылки на источники — в квадратных скобках по номеру в списке: [3], [7, 8].

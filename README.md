# RAG Retrieval Evaluation

Исследовательский проект, сфокусированный исключительно на оценке **Retrieval-части** (семантического поиска) RAG-систем для нормативно-правовых документов без использования генеративных моделей (LLM).

## Цель проекта
Сравнение эффективности различных моделей эмбеддингов и стратегий разбиения текста на фрагменты (чанкинга) для русскоязычных нормативных документов.

## Метрики качества
Оценка качества поиска производится с использованием стандартных метрик Information Retrieval:
- **Recall@k** — полнота поиска среди топ-$k$ документов
- **MRR (Mean Reciprocal Rank)** — средняя взаимная позиция первого релевантного документа

## Структура проекта
```text
├── data/
│   └── data.txt          # Нормативные документы для индексации
├── src/
│   ├── chunking.py       # Стратегии разбиения текста на чанки
│   ├── embeddings.py     # Модели эмбеддингов (SentenceTransformers / E5 / BGE)
│   ├── retriever.py      # Векторный индекс и поиск (FAISS)
│   └── eval.py           # Реализация метрик Recall@k и MRR
├── main.py               # Демонстрационный пайплайн оценки
├── run_real_data.py      # Пайплайн оценки на реальных данных из data/
├── requirements.txt      # Зависимости проекта
├── .gitignore            # Исключения для Git
└── README.md             # Документация проекта
```

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/DamirKx/rag.git
cd rag
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск оценки
Запуск пайплайна на реальных данных из директории `data/`:
```bash
python run_real_data.py
```
Либо запуск демонстрационного скрипта:
```bash
python main.py
```

# RAG Retrieval Evaluation

Исследовательский проект, сфокусированный исключительно на оценке **Retrieval-части** (информационного и семантического поиска) RAG-систем для нормативно-правовых актов (НПА) Республики Казахстан без использования генеративных моделей (LLM).

## Цель проекта
Сравнение эффективности различных моделей эмбеддингов, стратегий разбиения текста на фрагменты (чанкинга) и методов поиска (Dense FAISS, Sparse BM25, Hybrid RRF) для нормативных документов на русском и казахском языках.

## Поддерживаемые методы поиска
1. **Dense Retrieval (Векторный поиск):** плотные векторные представления на базе Transformer-моделей (`MiniLM`, `E5`, `BGE-M3`) с индексированием в `FAISS` (IndexFlatIP).
2. **Sparse Retrieval (Лексический поиск):** алгоритм `Okapi BM25` с адаптивной юридической токенизацией для точного поиска номеров статей, законов и числовых норм.
3. **Hybrid Retrieval (Гибридный поиск):** устойчивое слияние списков выдачи через алгоритм `Reciprocal Rank Fusion (RRF)`.

## Метрики качества
Оценка качества поиска производится с использованием стандартных метрик Information Retrieval:
- **HitRate@k (Accuracy@k)** — доля запросов, для которых хотя бы один релевантный документ найден в топ-$k$.
- **MRR (Mean Reciprocal Rank)** — средняя взаимная позиция первого релевантного документа.
- **Recall@k** — полнота поиска среди топ-$k$ документов.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/DamirKx/rag.git
cd rag
```

### 2. Создание и активация виртуального окружения
```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux / macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Подготовка данных (Adilet Legal QA)
Скрипт автоматически загружает датасет `olzhasAl/adilet-legal-qa-kz` с Hugging Face Hub, очищает текст от артефактов веб-парсинга (шапки и подвалы страниц) и формирует выборки:
```bash
python prepare_adilet_data.py --lang all --test-size 200
```

### 5. Запуск оценки поиска
Запуск сравнительного тестирования стратегий поиска на реальных правовых данных «Әділет» (эмбеддинги автоматически кэшируются на диск для мгновенных повторных запусков):
```bash
# Оценка на русском языке (100 вопросов, топ-3):
python run_adilet_eval.py --lang rus --test-size 100 --top-k 3

# Оценка на казахском языке:
python run_adilet_eval.py --lang kaz --test-size 100 --top-k 3
```

### 6. Интерактивный поиск по законам (CLI)
Вы можете задавать любые произвольные вопросы по законодательству в интерактивном консольном режиме:
```bash
# Запуск гибридного поиска (Dense FAISS + Sparse BM25):
python ask.py --mode hybrid

# Только семантический поиск:
python ask.py --mode dense

# Только поиск по номерам статей и ключевым словам:
python ask.py --mode bm25
```

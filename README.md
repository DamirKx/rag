# RAG Retrieval Evaluation

Данный проект представляет собой исследовательскую работу (курсовую), сфокусированную исключительно на **Retrieval-части** (поиске) RAG-систем для нормативных документов вуза. В проекте не используется генерация (LLM).

## Цель проекта
Сравнение различных моделей эмбеддингов и стратегий чанкинга (разбиения на фрагменты) на двуязычном корпусе (русский и английский) нормативных документов вуза. 

## Метрики качества
Оценка качества поиска (retrieval) производится с использованием стандартных метрик информационного поиска:
- **Recall@k** (полнота на k документах)
- **MRR** (Mean Reciprocal Rank)

## Структура проекта
- `data/` - директория для хранения сырых и обработанных нормативных документов, а также датасета с вопросами для оценки (qrels).
- `src/` - исходный код проекта:
  - `chunking.py` - функции для различных стратегий чанкинга (фиксированный размер, по предложениям, рекурсивный и т.д.).
  - `embeddings.py` - обертки для загрузки и использования эмбеддинг-моделей (multilingual E5, BGE-m3, LaBSE и др.).
  - `retriever.py` - логика построения векторного индекса (FAISS) и поиска.
  - `eval.py` - реализация метрик Recall@k и MRR.
- `notebooks/` - Jupyter ноутбуки для экспериментов, EDA и визуализации результатов.

## Установка
1. Создайте виртуальное окружение: `python -m venv venv`
2. Активируйте его (Windows): `venv\Scripts\activate`
3. Установите зависимости: `pip install -r requirements.txt`
